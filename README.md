# MNEME Landing Page

Marketing page for MNEME, a note product described as "Your Mind. Remembered."

The page is one HTML document with a canvas background, a feature section, and a button that opens the live note app: [note-application-kappa.vercel.app](https://note-application-kappa.vercel.app).
